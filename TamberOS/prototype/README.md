# Clickable UI concept

Double-click `index.html` or open it in Chromium/Firefox. This is a standalone static browser prototype; no framework, server, accounts or internet connection required. It references the adjacent original SVG assets.

Clickable sections: Overview, Tamber AI, Game Mode, Files, System Center, Settings, Boot splash, Sign-in and First Run. Search overlay with `Ctrl+K`; Escape closes overlays. Settings toggles affect this page only. All metrics, content, clocks and game cards are **illustrative**. No data are uploaded.

To preview on a development machine: `python3 -m http.server 8000` from the repository root, then visit `http://localhost:8000/prototype/`.
