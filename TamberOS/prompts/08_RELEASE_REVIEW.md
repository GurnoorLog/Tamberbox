# Codex task 08 — release gate

Audit project claims against tests and evidence. Execute test suite, verify package licenses/signatures/hashes, smoke test Qt shell, validate offline mode, keyboard navigation and local-only APIs. For every feature label PASS, FAIL, SKIP or UNTESTED with platform/kernel versions. Build release notes, explicit known issues, instructions for backup/rollback and a test-only pre-alpha artifact. Do not use “stable” or “production” until board boots, updates and recovery have been demonstrated.
