# Codex task 06 — Game Mode

Create a controller/keyboard friendly game launcher built around registered local executable profiles. Do not package ROMs, proprietary BIOS, artwork or games. Store per-title metadata under user config; validate filenames/commands to avoid unsafe shell interpolation. Implement focus navigation, launch/return states, last launched, and accessibility. Show real installation availability, not fabricated covers. Acceptance: three locally created test entries, directional navigation, graceful exit/restore, no elevated privileges.
